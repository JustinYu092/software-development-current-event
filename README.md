# Software Development Current Event Project

## Project Overview

Topic: AI Coding Agents Gone Wrong: Data Loss, Sandbox Escapes, and Security Risks

Topic Summary: AI coding agents now run terminal commands, edit files, and interact with Git and databases, which gives them real power over developers' systems. Recent reports and security advisories show agents deleting live data and crossing the sandbox boundaries meant to contain them, through bugs in path handling, symlink resolution, and configuration files. This project compares these failures across three cases (Claude Code, OpenAI, and Gemini) and explains what developers can do to limit an agent's blast radius.
