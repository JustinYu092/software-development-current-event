## 🔄 GitHub Collaboration Workflow

Our team uses GitHub as a collaboration and project-management platform.

### Issues
GitHub Issues are used to assign and track project tasks such as:

- Researching the current event
- Finding and verifying credible sources
- Writing and reviewing the script
- Designing presentation slides
- Recording and editing the video
- Reviewing the final presentation

### Branches
Project work is completed on separate branches before being merged into `main`.

Examples:

```text
research-topic
script-draft
slide-design
video-edit
```

### Pull Requests

Changes from project branches are submitted through Pull Requests. Team members review and provide feedback on each other's work before changes are merged into `main`.

### Discussions

GitHub Discussions are used for team communication and important project decisions, including topic selection, presentation planning, feedback, and progress updates.
